## Trust Boundaries

| Boundary                                          | Description                                                        |
| ------------------------------------------------- | ------------------------------------------------------------------ |
| Provider feature metadata -> app feature controls | Snapshot/listFeatures metadata controls whether fast is available. |
| Persisted app preferences -> new agent config     | Stored feature preferences can be replayed into future launches.   |
| Composer controls -> daemon feature RPCs          | App controls send fast changes to live sessions.                   |
