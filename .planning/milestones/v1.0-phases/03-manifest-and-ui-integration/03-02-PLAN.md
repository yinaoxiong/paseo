## Trust Boundaries

| Boundary                                 | Description                                                                        |
| ---------------------------------------- | ---------------------------------------------------------------------------------- |
| Cursor SDK service -> daemon snapshot    | External SDK model metadata becomes local provider model/thinking/feature options. |
| App/client selections -> SDK send params | User-selected encoded ids and feature values become SDK `ModelSelection.params`.   |
| Provider config -> SDK discovery         | Local config may add model metadata but must not mask SDK failures.                |

| T-03-02-02 | Tampering              | `model-options.ts` decode path            | mitigate    | Decode stable ids through structured metadata and validate against discovered SDK metadata before assembling SDK params.                                        |
