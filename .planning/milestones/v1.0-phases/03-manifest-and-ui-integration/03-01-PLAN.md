## Trust Boundaries

| Boundary                               | Description                                                                                      |
| -------------------------------------- | ------------------------------------------------------------------------------------------------ |
| Provider manifest -> app/server UI     | Static provider copy and mode visuals cross into user-facing selection surfaces.                 |
| Provider snapshot -> creation controls | Dynamic mode availability controls whether a user can create a Sandbox or YOLO cursor-sdk agent. |
| Provider id -> icon resolver           | Provider ids choose brand icons or fallback icons in the app.                                    |

| T-03-01-02 | Information Disclosure | manifest diagnostics/copy             | mitigate    | Description states `CURSOR_API_KEY` requirement without exposing or probing secret values; no logs or tests print keys.                                         |
