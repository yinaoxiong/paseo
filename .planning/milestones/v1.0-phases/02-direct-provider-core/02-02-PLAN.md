<objective>
Implement the `cursor-sdk` local session lifecycle: provider-scoped SDK store path creation, strict secret-free persistence handles, create/resume preflight, explicit model/mode overrides, SDK run cancellation, and idempotent session cleanup.

Purpose: This turns the Phase 02 provider boundary into a resumable direct provider session while preserving fail-closed Sandbox behavior and YOLO safety semantics per D-05, D-08 through D-18.
Output: A `CursorSdkAgentSession` backed by an injectable SDK runtime, strict persistence helpers, and targeted tests for lifecycle, resume, cancellation, path containment, override failure, and secret hygiene.
</objective>

<threat_model>

## Trust Boundaries

| Boundary                                              | Description                                                                                                   |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| persisted `AgentPersistenceHandle` -> provider resume | Resume handles are loaded from disk and must be treated as untrusted input.                                   |
| persisted `storePath` -> local filesystem             | SDK store paths control local file reads/writes for `JsonlLocalAgentStore`.                                   |
| config/env -> SDK calls                               | `CURSOR_API_KEY` is read from provider runtime settings or process env and passed to SDK create/resume calls. |
| requested model/mode overrides -> SDK runtime         | User-provided overrides can alter sandbox state or model.                                                     |
| provider session -> SDK run                           | Cancellation and cleanup cross from Paseo session lifecycle into SDK runtime objects.                         |
