## Trust Boundaries

| Boundary                                      | Description                                                                        |
| --------------------------------------------- | ---------------------------------------------------------------------------------- |
| Cursor SDK stream -> Paseo timeline           | Untrusted SDK event objects become persisted timeline rows and WebSocket messages. |
| Cursor SDK terminal status -> agent lifecycle | SDK terminal states control foreground turn completion/failure/cancellation.       |
| SDK tool payloads -> ToolCallDetail           | Tool names/inputs/outputs influence normalized tool cards and permissions context. |
| user prompt -> canonical timeline             | User input becomes persisted timeline text exactly once.                           |
| diagnostics -> logs/snapshots                 | Error/correlation metadata may be shown to clients and stored in logs.             |
