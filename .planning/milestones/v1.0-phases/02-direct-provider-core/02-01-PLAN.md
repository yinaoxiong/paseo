## Trust Boundaries

| Boundary                              | Description                                                                                         |
| ------------------------------------- | --------------------------------------------------------------------------------------------------- |
| local config/env -> provider client   | `CURSOR_API_KEY` crosses from `$PASEO_HOME/config.json` or daemon env into the Cursor SDK provider. |
| provider snapshot -> clients          | Availability, diagnostic, model, and mode metadata are serialized to app/CLI clients.               |
| persisted provider config -> registry | `agents.providers.cursor-sdk` and `agents.providers.cursor` must stay isolated.                     |
| runtime mode metadata -> agent launch | Sandbox/YOLO labels and unattended semantics influence launch safety.                               |
